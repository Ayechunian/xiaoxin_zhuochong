# 小新桌宠

已加入状态联动的气泡对话和可开关的本机“顽皮童声”。点击、拖拽、走动、睡眠、醒来及四个屏幕边缘动作都会触发对应台词；详细设置见 [气泡对话与声音](DIALOGUE_SYSTEM.md)。

右键菜单的 `专注计时` 可启动 15、25 或 50 分钟专注。专注期间桌宠停止随机走动和主动闲聊，鼠标靠近或单击时显示剩余时间；结束后会用现有动作和气泡提醒休息。桌宠还会根据早晨、中午、晚上和深夜显示问候，并在整点提醒活动身体；详细行为见 [专注计时与时间反应](FOCUS_AND_TIME.md)。

右键菜单的 `提醒中心…` 会打开独立页面，可在其中新增、查看、延后、完成和删除本地提醒。到点后使用加粗深色文字与浅暖黄色气泡持续提示，单击桌宠即可确认；详细说明见 [本地提醒中心](REMINDERS.md)。

右键菜单的 `设置中心…` 可调整自动散步、散步频率、进入睡眠时间、对话气泡和顽皮童声。桌宠还会根据点击、拖拽、完成提醒、进入睡眠等行为显示小型心情徽章；设置和心情会保存在本机。

角色身份参考取自电视朝日《蜡笔小新》官方角色页中的野原新之助透明 PNG。项目现在包含多组高清透明动作素材，运行时生成 78 帧高清动画；窗口默认约 110×130 像素，放大后仍从高清帧缩放，避免使用低分辨率图片放大造成模糊。

素材来源：<https://www.tv-asahi.co.jp/shinchan/character/>（页面中的 `img/01.png`）。

## 启动

最省事的方式是双击 `release\小新桌宠.exe`。这是独立单文件版，不需要安装 Python，也不需要保留项目目录。提醒数据保存在 `%LOCALAPPDATA%\XiaoxinDesktopPet`，重新替换 EXE 不会丢失。

Windows 10/11 64 位。若目录内附带 runtime，直接双击 `start.bat`，无需全局安装 Python。否则先安装 Python 3.10+，双击 `setup.bat` 安装项目独立环境，再双击 `start.bat`。首次安装依赖需要联网。

依赖使用官方 PySide6-Essentials，提供 PySide6.QtCore、QtGui、QtWidgets 和 QtTest，无需安装本项目不使用的 Addons 模块。

默认待机会呼吸并每隔约两秒眨眼；等待 5–12 秒后随机走动。走路使用用户提供的新六张独立关键帧，按图片从左到右、从上到下的顺序循环播放，完整循环约 0.6 秒，并在屏幕边缘转向。系统连续 60 秒无操作后切换为侧躺睡眠并显示动态 `Z`，恢复操作后醒来。鼠标靠近时会转头张望并看向鼠标；单击时跳起受惊；两秒内连续点击四次会生气并抖动；按住拖动时会换成双手上举、双腿挣扎的悬空姿势，松开后恢复。

右键菜单可放大、缩小、恢复默认大小、重置位置或退出。也可用 `Ctrl++`、`Ctrl+-`、`Ctrl+0` 调整大小；范围为默认尺寸的 55%～200%，每次变化 15%。窗口透明、无边框、置顶，不占任务栏。

## 目录

```text
main.py            程序入口、导出素材、启动检查
pet/art.py         角色缩放与多状态动画；按状态帧数生成
pet/window.py      五状态逻辑与桌面交互
assets/character.png  官方角色页的角色参考素材
assets/poses/      九张高清透明动作原图
assets/            导出的 78 张高清状态动画 PNG
runtime/           随项目附带的独立 Python 与依赖（如已部署）
requirements.txt   依赖范围
requirements-lock.txt  本机验证的精确版本（如已部署）
setup.bat          标准 Python 的独立环境安装脚本
start.bat          启动
```

程序从 `assets/character.png` 载入角色并生成动画，因此该文件不可删除。要换美术，可替换同名透明 PNG。睡眠阈值在 `pet/window.py` 的 `sleep_after`。

## 验证与排错

在本目录打开终端，使用 `runtime\python.exe main.py --smoke-test` 检查所有状态绘制并在约 1.6 秒后退出；使用 `runtime\python.exe main.py --export-assets` 导出素材，不覆盖已有图片。常规环境改用 `.venv\Scripts\python.exe`。

如果双击无反应，运行 `runtime\python.exe main.py` 查看错误。退出通过右键菜单完成。当前版本不含开机自启、联网聊天、重力或窗口攀爬；语音使用 Windows 本机 SAPI，不需要联网。跨屏拖动可用，自动走动限制在当前屏幕。高分屏按 Qt 的逻辑像素缩放。
